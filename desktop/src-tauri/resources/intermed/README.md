# Bundled InterMed

This directory holds the pinned InterMed executable used by `diagnose_instance` for
read-only static compatibility analysis. Platform binaries are generated by
`scripts/fetch-intermed.sh` and are not committed.

The release workflow verifies upstream SHA-256 checksums for published archives. InterMed
does not publish an Intel macOS archive, so that release job builds the pinned commit from
source. Tauri bundles this directory under `intermed/`; production never resolves InterMed
from the user's `PATH`.

InterMed is an alpha static analyzer. Its findings are normalized into kobeMC's own
compatibility DTO before they reach the agent or UI. A static pass is not runtime launch
proof.
